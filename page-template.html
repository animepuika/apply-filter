These scores are keyword matching, not judgement. They rank what is worth your attention, nothing more. Before you apply to any of them, ask the agent to run the real hundred point rubric from runbook.md against the full description. It reads the whole posting and it disagrees with this number often.

How to use this

Tick a role once you have applied. The ticks are saved in this browser only, so they follow this device and nothing else. The durable record is applications.md in the workspace, which is where you should log anything you want to still have in three months.

This page is a snapshot taken on 1 Sep 2026. Postings close. To refresh it, run node scripts/fetch-jobs.mjs and ask for the page to be republished.

Where these come from

Company job boards read directly (Greenhouse, Lever, Ashby), plus five remote job aggregators: Remote OK, Remotive, Arbeitnow, Jobicy and Himalayas. Sources marked via on a row came from an aggregator rather than the employer's own board, so check the posting is still open before you spend time on it.

What the labels mean

Bands follow the thresholds in runbook.md: strong at 75 and above, worth applying from 55, a stretch from 40, and below that a skip. Open to Latvia means the posting does not restrict remote work to a list of countries that excludes you. Confirm hiring means it might, and you should ask before spending an evening on the application. Years is the experience floor read out of the posting body, which is the one place it is ever stated: a role titled Engineer I can still demand five years.
